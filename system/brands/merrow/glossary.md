# Merrow — словарь

Одно понятие — одно слово во всём продукте. Колонка «не пишем» — слова,
которые путают пользователя, даже если они верны. Эта колонка — проверка:
`npm run check` найдёт такое слово в текстах продуктов бренда.

| слово | что значит | не пишем | заметка |
|---|---|---|---|
| Order | покупка клиента с оплатой и доставкой | Purchase | |
| Customer | тот, кто купил или зарегистрировался | Client, User, Buyer | User — только сотрудники магазина |
| Product | то, что продаём, со всеми вариантами | Item, Good | |
| Variant | конкретный размер или цвет товара | Option | SKU — код варианта, в таблицах можно |
| Stock | сколько единиц есть на складе | Inventory level, Qty | раздел называется Inventory |
| Fulfil | собрать и отправить заказ | Process, Complete | британское написание |
| Refund | вернуть деньги | Reimburse, Chargeback | Chargeback — только банковский спор |
| Return | клиент возвращает товар | — | не путать с Refund: возврат товара ≠ возврат денег |
| Archive | убрать из списков, можно вернуть | Hide, Disable | |
| Delete | удалить без возможности вернуть | Remove | только для необратимого |
| Copy | скопировать в буфер обмена, чтобы вставить в другом месте | — | после действия: «Order number copied». Новая запись из старой — не Copy, слова пока нет |
| Draft | сохранено, но не опубликовано | Unpublished, Pending | |
| Sales channel | где продаётся товар: сайт, маркетплейс | Platform, Outlet | Web store — название канала, так можно |
