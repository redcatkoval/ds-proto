# C-001 Таблица записей

**Состояние:** принят — стал компонентом DataTable
**Кто заявил:** пример, заведён при сборке прототипа
**Дата:** 2026-10-24
**Где нужен:** Список клиентов — вид «таблица» с колонками город, статус, последний контакт
**Из чего собирается:** сейчас ListItem в несколько строк

## Зачем

Менеджеру нужно сравнить клиентов по нескольким полям сразу и отсортировать
по колонке. ListItem показывает две строки текста — сравнивать по нему нельзя.

## Что пробовали

RecordList — черновик, тот же ListItem внутри. Колонок у него нет.
