# C-002 Действие в строке таблицы

**Состояние:** заявлен
**Кто заявил:** агент
**Дата:** 2026-10-24
**Где нужен:** Orders — в строке заказа кнопка, которая убирает заказ из списка (Archive order)
**Из чего собирается:** сейчас выбор строк флажками и кнопка «Archive orders» в полосе инструментов

## Зачем

Человек хочет убрать один заказ из списка, не открывая его и не выбирая флажком.
Кнопке в строке негде стоять: у DataTable нет места под действия строки.

## Что пробовали

- Button в ячейке — шаблон «Список записей» запрещает кнопки в строке; клик и Enter
  по кнопке всплывают до строки и открывают заказ (DataTable останавливает их только
  у флажка).
- DropdownMenu в отдельной колонке — восьмая колонка нарушает правило 1 DataTable;
  меню из одного пункта нарушает правило 1 DropdownMenu. Всплытие клика то же.
- Поставить действие внутрь существующей ячейки (Total) — смешивает данные и
  действие, ломает выравнивание чисел.

Нужно свойство DataTable для действий строки (например, `rowActions`) — своя
колонка вне счёта семи и остановка всплытия клика, как у флажка.
