# C-003 Подтверждение сделанного действия

**Состояние:** принят, срочно — 2026-10-24, владелец системы; появился черновик Toast
**Кто заявил:** агент
**Дата:** 2026-10-24
**Где нужен:** Order detail — иконка копирования рядом с номером заказа: после нажатия сказать, что номер скопирован
**Из чего собирается:** сейчас ничего — номер уходит в буфер молча

## Зачем

Копирование ничего не меняет на экране: человек не знает, сработало ли нажатие,
и жмёт ещё раз или вставляет наугад. Нужно короткое сообщение рядом с кнопкой
или внизу экрана («Order number copied»), которое само исчезает и слышно диктору
(aria-live). То же понадобится после других тихих действий — например,
Archive order.

## Что пробовали

- IconButton — свойства для состояния «сделано» нет; сменить иконку на check
  на время нельзя без своего кода в продукте.
- StatusBadge или Tag рядом с кнопкой — это статус записи, а не отклик на
  действие; сам не исчезает и диктору не объявляется.
- Modal — черновик, и подтверждать копирование окном слишком тяжело.

Формулировки «скопировано» в словаре и формулировках бренда Merrow нет —
её нужно добавить вместе с компонентом.

## Решение

Принят по быстрому пути: минимальный Toast — одно короткое сообщение внизу
экрана, исчезает само через 4 секунды, читается диктором, без кнопок и вариантов.

- компонент: `packages/ui/src/components/toast/`
- контракт: `system/core/contracts/toast.md`
- правило линтера: `system/core/rules/toast.json` (один Toast на экран)

Вызов из продукта:

```tsx
const [toast, setToast] = useState<string | null>(null);
// после действия: setToast("Order number copied")
<Toast message={toast} onHide={() => setToast(null)} />
```

Тексты Merrow (тон голоса: просто, как в предложении, без восклицаний):
«Order number copied» — копирование номера, «Order archived» — Archive order.
Не пишем: «Copied!», «Successfully copied», «Done».
