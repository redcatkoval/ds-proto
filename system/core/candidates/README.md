# Кандидаты

Чего в системе нет, но уже понадобилось. Один файл — один кандидат:
`C-<номер>-<короткое-имя>.md`. Номер — следующий по порядку.

Заявить может кто угодно: дизайнер, разработчик, агент. Агент обязан
заявить кандидата, если для экрана не хватает компонента, — и собрать
экран из того, что есть, а не рисовать недостающее сам.

Шаблон:

```
# C-002 Название

**Состояние:** заявлен
**Кто заявил:** имя или «агент»
**Дата:** ГГГГ-ММ-ДД
**Где нужен:** экран и место на нём
**Из чего собирается:** чем закрыт пробел сейчас

## Зачем

Что пользователь должен сделать и почему существующие компоненты не подходят.

## Что пробовали

Какие компоненты рассматривали и почему отказались.
```

Состояния: заявлен → разобран → принят (появляется черновик) или отклонён (с причиной).
