## Коротко

Аватар всегда знает имя и стоит рядом с ним.

## Правила

### 1. Имя обязательно

name передаётся всегда, даже с фотографией.

**Почему:** Из имени берутся инициалы и подпись для диктора.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

### 2. Рядом с именем

В списке аватар стоит рядом с именем.

**Почему:** По двум буквам запись не узнать.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Совпадает ли имя аватара с именем в строке — это разные свойства, их не сверяют.
