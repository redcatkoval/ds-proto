## Коротко

Кнопка — глагол, который делает то, что написано. В ряду одна главная, отмена слева от действия, необратимое — красное и с подтверждением.

## Правила

### 1. Одна основная кнопка в ряду

Среди кнопок одного ряда только одна основная (variant="primary"). Остальные — secondary или ghost.

**Почему:** Две основные кнопки рядом не говорят, какое действие главное, и человек останавливается.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Отправка формы — последней

Кнопка с type="submit" стоит последней в своём ряду: сначала «Cancel», потом «Save».

**Почему:** Глаз заканчивает ряд на главном действии. Правило про порядок в разметке, а не «справа»: в языках справа налево порядок на экране меняется, смысл — нет.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 3. Необратимое — красное и с подтверждением

Кнопка необратимого действия — variant="danger", и перед выполнением продукт спрашивает подтверждение.

**Почему:** Что действие нельзя отменить, по коду не узнать — это видит только человек.

**Кто следит:** человек — смотрит на ревью

### 4. Подпись — глагол из словаря

Текст кнопки называет результат и берётся из словаря бренда: «Refund €42.00», а не «Confirm».

**Почему:** По подписи человек решает, нажимать ли, ещё не прочитав остальной экран.

**Кто следит:** совет — не обязательно, но так лучше

### 5. Вид меняется только свойствами

className и style кнопка не принимает: вид задают только variant, size и icon.

**Почему:** Иначе в продукте появляются «почти кнопки», которые система не узнаёт и не обновляет.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

## Чего машина не видит

- Кнопку внутри другого компонента (EmptyState, Modal): правила «одна основная» и «отправка последней» смотрят на вызовы в продукте, а не внутрь системы.
- Ряд, собранный из массива через .map(): соседей не видно, такой случай уходит в «не проверено».
