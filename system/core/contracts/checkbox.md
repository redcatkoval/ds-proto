## Коротко

Флажок применяется после сохранения и всегда подписан.

## Правила

### 1. Подпись есть всегда

label не пустой, даже когда он спрятан через hideLabel.

**Почему:** Без подписи флажок — квадрат без смысла.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Частичный выбор — только у группы

indeterminate ставится только флажку, который управляет группой.

**Почему:** У одиночного флажка нет «частично».

**Кто следит:** человек — смотрит на ревью

### 3. Подпись нажимается

Нажатие по подписи переключает флажок.

**Почему:** Квадрат — маленькая цель.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

## Чего машина не видит

- Подпись из выражения — «не проверено».
