## Коротко

Таблица для сравнения записей: до семи колонок, числа справа, строка открывает запись.

## Правила

### 1. Не больше семи колонок

В columns не больше семи столбцов. Остальное — в карточку записи.

**Почему:** Широкую таблицу листают вбок и теряют строку.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Числа — по правому краю

Деньги и количества выравниваются по правому краю.

**Почему:** Так разряды стоят друг под другом и суммы сравнивают взглядом.

**Кто следит:** человек — смотрит на ревью

### 3. Пусто — словами бренда

Пустая таблица говорит словами из формулировок бренда.

**Почему:** Одинаковая пустота во всём продукте не пугает.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

## Чего машина не видит

- Колонки, переданные переменной: число узнаётся при отрисовке — «не проверено».
