## Коротко

Меню из двух и больше действий. Необратимые — последними и красным.

## Правила

### 1. Действий два и больше

В items не меньше двух действий. Одно действие — это Button, а не меню.

**Почему:** Меню из одного пункта — лишний клик.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Необратимые — последними

Пункты с destructive: true идут в конце списка.

**Почему:** Опасное не должно стоять под рукой первым.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 3. Красный — по признаку

Цвет необратимого пункта ставит сам компонент по destructive.

**Почему:** Цвет не забудут.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

### 4. Подпись — с чем действия

label: «Order actions».

**Почему:** Диктор слышит только подпись троеточия.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Список действий, собранный в рантайме, — «не проверено».
- Не проставленный destructive у удаления машина не заметит: необратимое узнают только по смыслу.
