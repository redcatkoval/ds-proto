## Коротко

Ошибка говорит, как исправить, а не что сломалось.

## Правила

### 1. Внутри полей — через error

У TextInput, TextArea и Select ошибку передают свойством error.

**Почему:** Поле само свяжет сообщение с собой для диктора.

**Кто следит:** человек — смотрит на ревью

### 2. Как исправить

Сообщение говорит, какое значение нужно.

**Почему:** «Invalid» не помогает исправить.

**Кто следит:** совет — не обязательно, но так лучше
