## Коротко

Иконка-кнопка всегда подписана словами, даже если подписи не видно.

## Правила

### 1. Подпись всегда есть

label не пустой: он звучит для диктора и всплывает при наведении.

**Почему:** Без подписи кнопку не найти ни на слух, ни поиском.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Подпись — что произойдёт

Подпись называет действие: «Close», а не «Cross».

**Почему:** Человек нажимает ради результата, а не значка.

**Кто следит:** человек — смотрит на ревью

### 3. Не для необратимого

Удаление и другие необратимые действия — Button danger с текстом.

**Почему:** Значок легко нажать случайно.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Подпись, собранную выражением (`Call ${name}`): что придёт при отрисовке, неизвестно — «не проверено».
