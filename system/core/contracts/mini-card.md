## Коротко

Одно число на карточку, не больше четырёх карточек в ряд.

## Правила

### 1. Не больше четырёх в ряд

Среди соседей не больше четырёх карточек.

**Почему:** Пятое число уже не сравнивают — его пропускают.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Число с пояснением

caption объясняет период или базу сравнения.

**Почему:** «48» без «за неделю» ничего не говорит.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Есть ли у числа понятная база сравнения — вопрос смысла.
