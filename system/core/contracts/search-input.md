## Коротко

Один поиск на экран, подпись говорит, где ищем.

## Правила

### 1. Один поиск на экран

На одном экране не больше одного SearchInput.

**Почему:** Два поля поиска — непонятно, где искать.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Подпись — где ищем

label называет область: «Search orders».

**Почему:** Диктор не видит, над чем поле.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Экран из нескольких файлов: поиск считается в каждом файле отдельно.
