## Коротко

Короткий список вариантов. Длинный — с поиском, два-три — Toggle.

## Правила

### 1. Не больше пятнадцати вариантов

В options не больше пятнадцати вариантов.

**Почему:** Длинный список листают, а не выбирают.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Подпись внутри

Подпись — свойство label.

**Почему:** Как у полей ввода.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

## Чего машина не видит

- Варианты из переменной: их число — «не проверено».
