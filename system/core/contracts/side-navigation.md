## Коротко

Одна на продукт, до восьми разделов.

## Правила

### 1. Не больше восьми разделов

В items не больше восьми пунктов.

**Почему:** Длинное меню читают, а не узнают.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Служебное — внизу, не больше трёх

В footerItems не больше трёх пунктов.

**Почему:** Служебное не должно спорить с работой.

**Кто следит:** машина — проверяется при каждом `npm run check`

## Чего машина не видит

- Пункты из переменной — «не проверено».
