## Коротко

Метка — категория записи. Не больше трёх подряд, цвет всегда значит одно и то же.

## Правила

### 1. Не больше трёх рядом

Среди соседей одного родителя не больше трёх меток.

**Почему:** Четыре метки читаются как шум, главное теряется.

**Кто следит:** машина — проверяется при каждом `npm run check`

### 2. Один смысл — один цвет

Одна и та же категория во всём продукте одного цвета.

**Почему:** Иначе цвет перестаёт что-то значить.

**Кто следит:** человек — смотрит на ревью

### 3. Не нажимается

Метка не кнопка и не принимает обработчиков.

**Почему:** Для фильтра есть FilterChip.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

## Чего машина не видит

- Метки, собранные через .map(): их число известно только при отрисовке.
