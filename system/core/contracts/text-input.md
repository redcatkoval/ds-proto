## Коротко

Поле с подписью внутри. Тип — по содержанию.

## Правила

### 1. Подпись внутри

Подпись — свойство label; отдельный Label рядом не ставится.

**Почему:** Две подписи у одного поля сбивают диктор и глаз.

**Кто следит:** компонент — заложено в него самого, нарушить нельзя

### 2. Тип по смыслу

type — email, tel, number по содержанию.

**Почему:** На телефоне откроется нужная клавиатура.

**Кто следит:** человек — смотрит на ревью

## Чего машина не видит

- Уникальность id на экране, если поля в разных файлах.
