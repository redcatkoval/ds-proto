## Коротко

## Правила

### 1. Не больше шести разделов

В items не больше шести пунктов.

**Почему:** Больше не помещается в одну строку на ноутбуке.

**Кто следит:** машина — проверяется при каждом `npm run check`

## Чего машина не видит

- Пункты из переменной — «не проверено».
