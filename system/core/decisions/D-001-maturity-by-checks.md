# D-001 Ступень зрелости считается, а не ставится

**Дата:** 2026-10-24

Ступень (черновик → готов → стабилен) вычисляет `tools/snapshot/build.mjs`
по проверкам при каждом прогоне. Руками её не поставить.

Следствия:

- новое нарушение в продукте опускает ступень в тот же прогон;
- «не проверялось» — отдельное состояние, оно не считается пройденным;
- последний шаг к стабильному — сверка контракта человеком: поле
  «Сверено человеком» в шапке контракта. Машина его не ставит.

Из чего следует: проверки и их результаты — `system/generated/snapshot.json`,
поле `maturity` у каждого компонента.
