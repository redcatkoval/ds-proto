# Шаблоны экранов

Готовые раскладки, с которых начинается любой новый экран. Шаблон говорит,
из каких компонентов и в каком порядке собран экран, и показывает живой
пример в продукте. Агент начинает новый экран с шаблона, а не с чистого листа:
так экраны разных продуктов и разных людей устроены одинаково.

Экран в `product.json` продукта указывает свой шаблон полем `pattern`.
Не подходит ни один — это повод заявить кандидата в шаблоны, а не собрать «своё».
