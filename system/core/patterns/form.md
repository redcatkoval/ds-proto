# Форма записи

**Когда:** создать или изменить запись: товар, клиента.
**Пример:** apps/crm/src/screens/ProductScreen.tsx
**Компоненты:** Breadcrumbs, Tabs, Panel, TextInput, TextArea, Select, Checkbox, Button, EmptyState

## Как устроен

1. Путь и название записи; если частей много — Tabs (до шести).
2. Поля сгруппированы в Panel по смыслу: «General», «Sales channels».
3. Поля в две колонки, длинные (описание) — во всю ширину.
4. Внизу справа: «Cancel», затем основная кнопка type="submit" с глаголом из словаря: «Save product».
5. Ошибка поля — свойством error, показывается после попытки сохранить.

## Не делай

- Switch в форме с кнопкой сохранения — там Checkbox.
- Кнопка сохранения первой или наверху формы.
- Ошибки на каждую букву.
