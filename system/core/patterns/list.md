# Список записей

**Когда:** раздел, где много однотипных записей и их сравнивают по полям: заказы, товары, клиенты, склад.
**Пример:** apps/crm/src/screens/OrdersScreen.tsx
**Компоненты:** MiniCard, Panel, SearchInput, FilterChip, DataTable, StatusBadge, Tag, EmptyState, Button

## Как устроен

1. Шапка: название раздела. Справа — не больше двух кнопок, основная одна и последняя.
2. Ряд показателей — до четырёх MiniCard. Можно без него.
3. Panel без отступов (flush). Сверху полоса инструментов: SearchInput и до пяти FilterChip.
4. DataTable: до семи колонок, деньги и количества по правому краю, строка открывает запись.
5. Поиск ничего не нашёл — вместо таблицы EmptyState с illustration="no-results" и кнопкой сброса.

## Не делай

- Карточки вместо таблицы, когда записи сравнивают по полям.
- Кнопки действий прямо в строке — действия с записью уходят в DropdownMenu.
- Второй поиск или фильтры в двух местах.
